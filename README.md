# Odin Recipes

This project is a basic recipe website built as part of [The Odin Project](https://theodinproject.com) Foundations curriculum. It consists of a main index page that links to several individual recipe pages.

## Skills Demonstrated

By completing this project, I will have demonstrated the ability to:
* Set up a local Git repository and sync it with GitHub using SSH.
* Use basic command-line navigation and file management commands (`cd`, `mkdir`, `touch`).
* Structure a multi-page website using semantic HTML5 boilerplate and elements.
* Organize project files cleanly using relative paths for links and images.
* Write clean, atomic Git commit messages following best practices.
